# Task 3 – Landing Page

A modern, fully responsive landing page built with React, Vite, Tailwind CSS, and Framer Motion.

## Features
- Hero Section with animations
- Product Showcase
- Pricing with Monthly/Yearly toggle
- Feature Comparison Table
- Customer Testimonials Carousel
- FAQ Accordion with search
- Blog Preview
- Contact Form with validation
- Dark/Light Mode
- Back-to-Top Button
- Scroll Progress Indicator
- Sticky Navigation

## Tech Stack
- React 18
- Vite
- Tailwind CSS 4
- Framer Motion
- AOS
- React Icons

## Installation

```bash
npm install
npm run dev
